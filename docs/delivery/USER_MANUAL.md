# 用户操作手册

适用对象：财政局业务人员、纪委监督人员、联合试点验收人员。

适用环境：政府联合试点单租户环境。用户应通过客户指定的 HTTPS 地址访问系统，不在公网样板环境上传真实业务数据。

## 1. 角色与职责

| 角色 | 典型人员 | 可执行操作 | 不应执行操作 |
| --- | --- | --- | --- |
| `admin` | 信息中心管理员、项目管理员 | 用户管理、环境策略查看、数据库来源审计、AI/OCR/连接器配置、审计日志查看 | 代替业务部门确认风险处置结论 |
| `auditor` | 财政监督人员、审计业务人员 | 创建任务、导入脱敏样本、查看风险、更新整改状态、导出报告和密封包 | 修改系统安全策略、创建管理员账号 |
| `viewer` | 纪委监督人员、领导查看账号、联合验收查看账号 | 查看任务、查看风险、查看整改状态；审计留痕由管理员展示或导出 | 创建任务、上传证据、导出敏感结果 |

联合试点建议：

- 财政局业务人员使用 `auditor` 账号完成数据导入、任务复核和报告导出。
- 纪委监督人员使用 `viewer` 账号查看问题线索、处置过程和整改状态；如需参与复核，可由客户授权配置为 `auditor`。
- 信息中心使用 `admin` 账号完成账号、策略、日志、备份和健康检查。

## 2. 登录与个人会话

1. 打开客户指定的系统地址。
2. 输入账号和密码登录。
3. 登录后确认页面显示当前用户角色。
4. 完成操作后点击退出登录。

注意事项：

- 不要共用账号。验收截图和审计日志会记录操作人。
- 多次登录失败后，应联系信息中心管理员排查账号锁定、密码错误或服务状态。
- 服务重启后如出现会话失效，重新登录即可；如频繁失效，应由管理员检查 `AUDITLENS_SESSION_SECRET` 是否保持一致。

## 3. 财政局业务人员操作流程

### 3.1 创建财政监督样板任务

适用场景：正式演示、培训、验收前确认系统主流程可用。

操作步骤：

1. 使用 `auditor` 账号登录。
2. 进入任务或审计工作台。
3. 创建财政监督样板任务。
4. 等待任务完成，进入任务详情。
5. 查看风险发现、规则编码、风险等级、证据摘要和建议处置。

预期结果：

- 系统生成一条任务记录。
- 任务详情可显示风险发现。
- 风险发现包含规则编码、规则名称、风险等级、审计依据和建议处置。

验收证据：

- 任务列表截图。
- 任务详情截图。
- 至少一条风险发现的详情截图。

### 3.2 导入脱敏财政监督样例

适用场景：验证客户化样本是否能进入规则分析流程。

操作步骤：

1. 确认样本已经按客户要求脱敏。
2. 由数据负责人登记样本名称、来源系统、脱敏方式和样本批次。
3. 使用 `auditor` 账号选择文件审计或批量导入入口。
4. 上传预算、采购、支付、凭证或整改台账样本。
5. 检查导入预览和字段映射结果。
6. 确认导入后生成任务。

预期结果：

- 中文字段和业务名称能正常显示。
- 系统能识别预算、采购、支付、凭证等主要字段。
- 任务详情能显示导入批次和风险发现。

注意事项：

- 未经批准不得上传真实个人信息、供应商敏感信息、涉密项目名称或完整凭证附件。
- 公开样板环境不得用于真实政府数据验证。

### 3.3 查看风险发现

操作步骤：

1. 打开任务详情页。
2. 按风险等级查看 `High`、`Medium`、`Low` 或 `Info` 结果。
3. 查看每条风险的规则编码、规则名称、命中摘要、证据摘要、缺失证据和建议补充数据。
4. 对需要人工复核的风险，记录复核意见。

业务判断原则：

- 系统输出是监督线索和规则识别结果，不直接替代审计结论。
- 采购公开数据缺少合同、验收或支付时，系统多按“补充数据建议”处理，不应直接认定违规。
- 高风险规则需要结合合同、支付、凭证、审批、整改佐证做人工复核。

### 3.4 证据追溯

操作步骤：

1. 在风险详情中查看证据摘要。
2. 对采购风险，核对项目编号、采购单位、公告阶段、预算金额、中标金额、合同编号、验收状态和来源链接。
3. 对预算和支付风险，核对预算项目、指标文号、项目库 ID、支付单号、会计凭证号和收款单位。
4. 对缺失证据项，按系统提示补充合同、验收、支付或凭证数据。

证据追溯要求：

- 每条正式验收风险至少保留一张风险详情截图。
- 对导出报告中的重点风险，保留对应数据样本行号或来源记录说明。
- 密封导出包用于交付留档时，应同时保存校验结果。

### 3.5 整改闭环

操作步骤：

1. 打开需要处置的风险发现。
2. 更新问题状态，例如待复核、整改中、已解决或已关闭。
3. 填写处置备注，说明核查过程、责任部门、补充材料或整改结论。
4. 如系统支持整改附件，上传经脱敏的整改佐证。
5. 保存后返回任务详情，确认状态已更新。

建议处置口径：

- “待复核”：线索成立性需要业务部门补证。
- “整改中”：确认需要整改，已明确责任部门和整改期限。
- “已解决”：整改材料已提交并通过复核。
- “已关闭”：经复核不构成问题，或已完成处置归档。

### 3.6 导出报告和密封包

操作步骤：

1. 在任务详情页选择 PDF 标准报告导出。
2. 检查报告是否包含任务信息、风险摘要、规则结果、证据摘要、整改状态。
3. 如需留档或移交，生成密封导出包。
4. 将 PDF、密封包、密封包校验结果和验收截图一并归档。

注意事项：

- 导出文件可能包含敏感业务信息，应按客户数据管理制度存放。
- `viewer` 角色不能创建任务或导出敏感结果。
- 密封包校验失败时，不得作为验收证据，应重新导出或联系管理员排查。

## 4. 纪委监督人员操作流程

### 4.1 查看联合监督任务

1. 使用纪委监督查看账号登录。
2. 打开任务列表，按任务名称、业务域、时间或风险等级筛选。
3. 进入任务详情查看风险发现、证据摘要和整改状态。

关注重点：

- 是否存在高风险财政资金支付或采购异常。
- 风险发现是否有可追溯证据。
- 整改状态是否有责任部门、处置备注和时间记录。

### 4.2 查看问题线索和整改进度

1. 在风险列表中筛选 `High` 和 `Medium` 风险。
2. 查看 `recommended_action` 或页面上的建议处置。
3. 核对处置备注是否说明整改依据、整改动作和复核结论。
4. 对需继续跟踪的问题，记录任务编号、风险编码和责任部门。

监督口径：

- 对采购链条缺失类规则，先作为补证或跟踪线索。
- 对支付无预算项目、凭证失衡、疑似重复支付、期末集中支付等规则，应优先纳入人工复核。
- 对 AI 解释内容，只作为辅助理解，最终以规则结果、业务证据和人工复核结论为准。

### 4.3 验收查看

纪委监督人员参与验收时，重点确认：

- `viewer` 账号只能查看，不能创建任务或导出敏感结果。
- 系统能展示审计留痕和关键操作记录。
- 风险发现能说明命中原因、风险等级、证据摘要和建议处置。
- 整改状态和备注保存后可复查。

## 5. 常见业务问题

| 问题 | 处理方式 |
| --- | --- |
| 看不到创建任务按钮 | 确认当前账号是否为 `auditor` 或 `admin` |
| 无法导出报告 | 确认当前账号权限；如为 `viewer`，需由授权人员导出 |
| 风险命中数量与预期不同 | 检查样本字段是否完整，重点核对金额、项目编号、指标文号、合同号、支付单号 |
| 采购项目提示证据链缺失 | 补充合同、验收、支付或凭证数据后复核 |
| AI 分析不可用 | 政府试点默认关闭 AI，不影响规则识别、报告导出和整改闭环 |
| 中文显示异常 | 联系管理员检查导入文件编码，建议使用 UTF-8 CSV 或标准 Excel |

## 6. 验收时用户侧需提交的材料

- 参训签到表或培训记录。
- 样本数据脱敏说明。
- 任务创建和任务详情截图。
- 风险发现截图。
- 整改状态更新截图。
- PDF 标准报告。
- 密封导出包及校验结果。
- 用户角色权限验证截图。
