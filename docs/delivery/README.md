# 联合试点正式交付文档包

适用范围：纪委、财政局、信息中心联合试点的正式交付与验收。本文档包面向单租户政府试点环境，默认先使用脱敏样例数据，受控真实小样本仅在客户书面批准并完成脱敏确认后导入。

不适用范围：本文档包不声明系统已经满足大范围生产上线、跨租户运营、等保测评完成或长期灾备体系要求。生产上线前仍需按客户安全、运维和数据管理制度完成专项评审。

## 交付使用顺序

1. 信息中心按系统管理员手册完成环境检查、账号准备、备份策略和能力开关确认。
2. 数据负责人按测试数据集说明准备脱敏样例，并记录样本来源、脱敏方式和导入批次。
3. 培训讲师按培训 PPT 大纲完成业务人员和管理员培训。
4. 验收组按联合试点正式验收清单逐项操作并收集证据。
5. 项目组将验收截图、导出 PDF、密封导出包、健康检查结果、备份恢复记录和签字页归档。

## 交付边界

- 角色边界：系统内置交付角色以 `admin`、`auditor`、`viewer` 为准。
- 数据边界：公网样板环境只使用脱敏样例；政府试点环境才允许导入批准后的受控真实小样本。
- AI 边界：政府试点默认 `aiEnabled=false`；启用 AI 前需完成客户审批，并在培训和验收材料中说明 AI 仅为辅助解释层。
- 集成边界：接口以现有 `docs/API.md` 为准，本文档只做集成视角补充，不新增接口契约。
- 运维边界：本文档覆盖试点验收所需的备份、恢复、健康检查和应急处置；生产级监控、容灾、审计制度需在上线前另行评审。
