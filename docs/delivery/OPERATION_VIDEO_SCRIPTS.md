# 操作视频脚本

本文档用于录制联合试点培训和验收视频。每个视频建议控制在 3 到 8 分钟，使用脱敏样例数据录制，不展示真实账号密码、secret、真实个人信息或未经批准的业务数据。

## 录制通用要求

- 使用客户认可的脱敏样例数据。
- 浏览器地址栏可显示内网试点地址，但不展示公网真实数据入口。
- 登录密码、API key、连接器 secret、session secret 不得入镜。
- 每段视频开头说明适用角色和目标。
- 每段视频结尾展示可作为验收证据的页面或导出物。

## 视频 1：登录与角色确认

对象：所有用户。

时长：3 分钟。

目标：展示用户登录、角色确认和退出登录。

镜头脚本：

1. 打开系统 HTTPS 地址。
2. 输入脱敏演示账号和隐藏密码。
3. 登录后查看当前用户角色。
4. 简要说明 `admin`、`auditor`、`viewer` 的差异。
5. 退出登录。

旁白：

“本视频演示联合试点环境的登录流程。系统要求一人一号，关键操作会进入审计留痕。财政业务人员通常使用 auditor，纪委查看人员通常使用 viewer，信息中心使用 admin。”

验收截图点：

- 登录成功页面。
- 当前用户角色。
- 退出登录入口。

## 视频 2：创建财政监督样板任务

对象：财政局业务人员、验收组。

时长：5 分钟。

目标：展示从创建样板任务到查看风险发现的主流程。

镜头脚本：

1. 使用 `auditor` 账号登录。
2. 进入任务工作台。
3. 创建财政监督样板任务。
4. 返回任务列表查看新任务。
5. 打开任务详情。
6. 展示风险发现列表、规则编码、风险等级和证据摘要。

旁白：

“样板任务用于快速验证系统主流程。正式客户化验收还需要使用脱敏业务样本再执行导入和规则分析。”

验收截图点：

- 任务创建成功。
- 任务详情。
- 风险发现详情。

## 视频 3：导入脱敏样本

对象：财政局业务人员、数据负责人。

时长：6 分钟。

目标：展示预算、采购、支付或凭证样本的导入流程。

镜头脚本：

1. 展示样本文件名，说明为脱敏样本。
2. 进入文件审计或批量导入入口。
3. 选择样本文件。
4. 查看字段映射或导入预览。
5. 提交导入。
6. 打开生成任务。

旁白：

“导入前必须确认样本已经脱敏。预算、采购、支付和凭证联动验证需要项目编号、指标文号、合同编号、支付单号和凭证号等关键字段。”

验收截图点：

- 样本文件名。
- 字段映射或导入预览。
- 导入后任务详情。

## 视频 4：查看风险与证据追溯

对象：财政局业务人员、纪委监督人员。

时长：6 分钟。

目标：展示如何理解风险发现，并回查证据。

镜头脚本：

1. 打开任务详情。
2. 筛选高风险或中风险。
3. 打开一条风险发现。
4. 展示规则编码、命中摘要、审计依据、证据摘要。
5. 展示缺失证据或建议补充数据。
6. 说明采购证据链或预算支付凭证联动口径。

旁白：

“风险命中是监督线索，不自动等同于违规结论。采购公开数据缺合同、验收或支付时，系统会提示补充证据，再由业务人员复核。”

验收截图点：

- 风险列表。
- 风险详情。
- 证据摘要和建议处置。

## 视频 5：整改状态更新

对象：财政局业务人员、纪委监督人员。

时长：5 分钟。

目标：展示问题处置和整改闭环。

镜头脚本：

1. 选择一条风险发现。
2. 修改状态为整改中或已解决。
3. 填写处置备注。
4. 保存。
5. 返回任务详情确认状态变化。
6. 使用查看账号展示状态可复查。

旁白：

“整改闭环需要记录处置依据和责任部门。纪委监督人员可以查看整改状态和备注，用于跟踪问题闭环。”

验收截图点：

- 修改前状态。
- 处置备注。
- 修改后状态。

## 视频 6：PDF 报告和密封导出包

对象：财政局业务人员、验收组、信息中心。

时长：6 分钟。

目标：展示标准报告导出、密封包生成和校验。

镜头脚本：

1. 使用 `auditor` 账号打开任务详情。
2. 点击 PDF 标准报告导出。
3. 打开 PDF，展示任务信息、风险摘要和整改状态。
4. 生成密封导出包。
5. 在终端执行 `seal-verify` 校验。
6. 展示 `OK` 输出。

旁白：

“PDF 用于业务汇报，密封包用于留档和移交。密封包通过校验后，才能作为完整验收证据。”

验收截图点：

- PDF 报告首页或目录。
- 密封包文件。
- `seal-verify` 输出 `OK`。

## 视频 7：管理员巡检

对象：信息中心、系统管理员。

时长：7 分钟。

目标：展示部署策略、健康检查、账号、日志和备份恢复证据。

镜头脚本：

1. 使用 `admin` 账号登录。
2. 查看部署策略，确认政府试点基线。
3. 打开 `/api/health`。
4. 打开 `/api/health/details`。
5. 查看账号角色列表。
6. 查看审计日志。
7. 展示备份命令和恢复演练输出。

旁白：

“管理员验收重点是环境可控、权限有效、数据可恢复、操作可追溯。AI 默认关闭不是故障，而是政府试点安全策略。”

验收截图点：

- 部署策略。
- 健康检查。
- 账号角色。
- 审计日志。
- 备份恢复输出。

## 视频 8：viewer 权限限制

对象：纪委监督人员、验收组。

时长：4 分钟。

目标：证明查看角色不能创建任务或导出敏感结果。

镜头脚本：

1. 使用 `viewer` 账号登录。
2. 打开任务列表和任务详情。
3. 尝试查找创建任务入口，说明不可用。
4. 尝试导出或说明导出按钮不可用。
5. 展示可以查看风险和整改状态。

旁白：

“viewer 适合纪委监督查看和领导查看。该角色可以查看结果，但不能创建任务或导出敏感结果，降低误操作和数据外发风险。”

验收截图点：

- `viewer` 当前角色。
- 任务详情可查看。
- 创建或导出能力不可用。

## 视频 9：常见故障处理

对象：信息中心、项目支持人员。

时长：8 分钟。

目标：展示验收期间常见故障的排查路径。

镜头脚本：

1. 展示应急预案文档。
2. 演示 `/api/health` 检查。
3. 演示登录失败时查看审计日志。
4. 演示导入失败时查看错误提示。
5. 演示密封包校验失败的处理口径。
6. 强调真实敏感数据误传时立即暂停和上报。

旁白：

“验收期间先保护数据安全，再恢复流程。涉及真实数据、权限越权或导出泄露时，应按 P0 事件处理。”

验收截图点：

- 健康检查。
- 错误提示。
- 应急预案对应章节。
