# 联合试点正式验收清单

适用场景：纪委、财政局、信息中心联合试点正式交付验收。

验收边界：本清单用于确认单租户政府试点环境、脱敏样例和受控真实小样本验证可交付；不等同于大范围生产上线、等保测评或长期运维服务验收。

结果填写口径：

- 通过：功能按步骤完成，证据材料齐全。
- 有条件通过：主流程通过，存在不阻断试点使用的优化项。
- 不通过：安全、权限、数据、导出或主流程存在阻断问题。
- 不适用：该项未纳入本次验收范围，需写明原因。
