# 销售与演示手册

## 核心定位

- 把 AuditLens 讲成`财政监督工作台`，不要讲成通用 SaaS 工具
- 先讲财政监督问题域，再讲系统功能
- AI 只作为解释层，不作为结论引擎
- 公网环境只用于汇报，真实数据只进入私有 PoC

## 5 分钟汇报路径

1. 打开样板环境首页，说明这只是汇报环境
2. 引导客户看 `预约汇报 / 申请 PoC` 的转化路径
3. 登录演示租户
4. 选择`财政监督`场景并生成样板任务
5. 展示风险图、重点问题、整改闭环
6. 导出财政监督标准 PDF 报告
7. 如果当前环境允许 AI，再展示 AI 辅助解释，并强调其只是辅助层

## 汇报后的标准动作

1. 发送政府 PoC 方案包
2. 约技术交流
3. 确认 PoC 范围、样例数据和部署环境
4. 确认是否允许真实数据、是否允许 AI

## 常见异议

- `为什么不用 Excel 或脚本？`
  AuditLens 把场景进入、规则识别、标准报告和整改闭环做成统一工作流，不再依赖零散人工操作。
- `AI 会替代审计判断吗？`
  不会。规则结果才是系统正式结论，AI 只负责解释和摘要。
- `公网环境能不能直接导入真实数据？`
  不能。真实数据只能进入私有 PoC 环境。
- `关闭 AI 后还能不能用？`
  可以。PoC 默认就是 AI 关闭，规则审计、报告和整改闭环不受影响。

## 包装方式

- 汇报包：样板环境、场景讲解、标准汇报材料、PoC 方案包
- PoC 包：私有部署、样例验证、受控真实数据小样本验证、验收清单
