# 政府 PoC 方案包

## 1. 产品概述

AuditLens 是面向政府财政监督场景的审计工作台，围绕预算执行、专项资金、集中支付、年末突击列支、重复支付和账务勾稽异常等问题域，提供规则识别、标准报告和整改闭环。

核心价值：

- 从财政监督场景进入，而不是从裸文件上传进入
- 用受控数据源模板和白名单表接入真实系统
- 输出可汇报的财政监督标准报告
- 将问题整改和审计留痕放在同一闭环中

## 2. 部署架构

- 公网样板环境：仅用于汇报和获取 PoC 机会
- 政府 PoC 环境：单租户部署于政务云或私有环境

推荐 PoC 结构：

- HTTPS 反向代理或网关
- AuditLens 应用节点
- 本地 SQLite 状态库 `data/platform.db`
- 可选的受控数据库连接
- 可选的 AI 服务，仅在明确允许时启用

## 3. 数据边界

- 公网样板环境只接收脱敏样例数据
- 政府 PoC 先跑脱敏样例，再导入受控真实数据小样本
- 数据库审计只能通过白名单模板和批准表名进行
- AI 调用始终在服务端发起

## 4. 角色模型

- `admin`：环境配置、AI 策略、用户管理、数据库审计
- `auditor`：文件审计、任务复核、整改更新、报告导出
- `viewer`：只读查看任务结果

## 5. 运维与恢复

- 健康检查：`/api/health`
- 主状态文件：`data/platform.db`
- 运行策略文件：`config/runtime.local.json`
- 备份范围：`data/platform.db` 与安全保存的 `config/runtime.local.json`

## 6. PoC 范围

- 部署一个单租户环境
- 创建管理员和所需的审计员 / 查看员账户
- 至少跑通一个财政监督样例任务
- 仅在批准后验证真实数据小样本
- 验证标准报告导出、密封导出和整改闭环

## 7. 交付结果

- 可运行环境
- 可登录与角色隔离
- 可创建财政监督任务
- 可输出专业风险结论
- 可导出财政监督标准报告
- 可跟踪整改状态与审计留痕
