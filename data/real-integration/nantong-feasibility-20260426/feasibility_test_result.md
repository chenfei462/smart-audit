# 江苏/南通公开真实数据可行性测试结果

测试日期：2026-04-26

## 测试范围

本次使用江苏县市级公开数据构造了 92 条真实数据样本，其中南通下辖县市区为主，另加入张家港、江阴等江苏县市作为横向校验样本。

- 财政/预算公开摘要：66 条，文件 `jiangsu_county_public_fiscal_summary_batch.json`
- 公共资源交易/采购公告：14 条，文件 `nantong_procurement_batch.json`
- 监督案件种子：12 条，文件 `nantong_case_seed_batch.json`

数据覆盖南通市本级、海门、海安、如皋、通州、崇川、如东、启东等地，字段按系统现有 batch import API 归一化。财政金额统一为万元；采购预算/中标金额统一为元。

## 规则命中情况

财政/预算公开摘要：

- `BUDGET-CLASS-001` 命中 2 条，主要提示功能分类/经济分类组合偏离。公开预算摘要缺少完整经济分类、指标文号、项目目录 ID，因此该规则可用于发现异常，但需要人工核对上下文。

采购/公共资源交易：

- `PROC-CHAIN-001` 命中 14 条，提示公告到合同到验收链条不闭合。因为本批数据大多来自公告/计划阶段，缺少后续合同与验收公告，这是符合公开数据现状的风险提示。
- `PROC-SPLIT-001` 命中 2 条，高风险，提示崇川城东街道老旧小区改造相关项目在短期内存在多个相似采购项目，需核对采购计划、分包依据和预算拆分说明。

## 可行性结论

系统对江苏县市级公开财政、采购、投资评审和监督线索数据具备可行性：

- 批量导入能力可用。三类真实数据 92 条均可入库，财政和采购导入拒绝行数为 0。
- 规则引擎可产生可解释结果。预算分类偏离、采购闭环缺失、疑似拆包等规则能在南通真实公告数据上触发，并生成可追踪的建议动作。
- 案件工作台可承接公开监督线索。海安投资评审、通州民生实事、崇川数据监督、如东/启东项目计划等数据可以转成案件种子并分配到责任单位或审计人员。
- 中文链路可用，但客户端必须按 UTF-8 发送 JSON。Windows PowerShell 字符串体和部分 curl 调用出现过乱码或请求体转义问题；Node UTF-8 字节发送验证通过。

当前公开数据不能完全验证系统的国库支付、会计凭证、合同支付入账三方闭环能力。公开网站通常没有 `payment_order_no`、`treasury_voucher_no`、`voucher_no`、`indicator_document_no`、`project_catalog_id` 等内部联查键。要证明完整财政监督闭环，需要至少一个县区提供脱敏的预算指标、国库支付、合同、会计凭证样本。

## 结论等级

建议定为“可进入县区 PoC，但需补齐内控数据联查样本”。

公开数据足够支撑展示、导入、规则触发、案件生成、来源留痕和区域对比；不足以单独证明真实支付链路和凭证链路的闭环审计效果。
