# 江苏县市公开数据 PoC 标准报告模板

## 1. 数据来源与覆盖
- 覆盖区域：江苏省、市、县区三级行政区，首批重点为南通下辖县市区、东台、江阴、昆山、江宁。
- 数据类型：公开财政收支汇总、公开统计指标、投资评审公开摘要、政府采购公告/成交/合同/验收阶段数据、案件种子。
- 来源证据：每条记录应记录来源标题、URL、发布日期、采集时间、原始行号、解析器版本。

## 2. 系统处理结果
- 导入数量、成功率、拒绝行、质量告警。
- UTF-8 中文往返结果。
- 区域标准化结果：province/city/county/normalized_region_code/display_name。
- 来源完整率和缺失来源风险。

## 3. 规则发现与解释
- 采购链条：按 announcement、award、contract、acceptance、payment 阶段解释缺失证据。
- 拆分采购：按采购单位、供应商、项目名称相似度、年度、金额区间、时间窗口评分。
- 公开财政轻量规则：收入/支出/统计指标异常波动、债务或政府性基金指标缺失、公开口径冲突。
- 每条发现应输出 severity_reason、missing_evidence、recommended_next_data。

## 4. 下一步内网补数清单
- 部门预算指标：指标文号、预算单位、项目名称、功能/经济分类、预算金额、执行金额。
- 采购合同：项目编号、合同编号、供应商、合同金额、签订/公告日期。
- 国库集中支付：支付单号、合同编号、收款单位、支付金额、支付日期。
- 会计凭证：凭证号、科目编码、摘要、借贷金额、记账日期。
- 问题整改台账：问题来源、责任单位、整改状态、整改期限、复核结论。
